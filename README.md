# Canado

A marketplace where every seller is in Canada and buyers are anywhere in the world. Auctions, Buy It Now and best offers, shipped only by Canada Post. Sellers pay one 3% final value fee: no listing fees and no subscriptions. Buyers pay Canado; Canado holds the money, deducts the fee and pays the seller.

## Run it

Requires Node.js 20 or newer.

```bash
npm install
cp .env.example .env      # optional for local testing
npm run seed              # optional demo seller, buyer and listings
npm start                 # http://localhost:3000
```

On first start the admin account is created and its password is printed in the terminal (or set `ADMIN_PASSWORD` in `.env`). Sign in and open `/admin`.

Run the automated end-to-end test (91 checks covering the full buy, sell, ship, refund and payout cycle):

```bash
npm test
```

## What is in it

| Area | What works |
|---|---|
| Accounts | Register, sign in, password reset, saved shipping address |
| Canadian sellers only | Seller application with Canadian address, postal code checked against province, phone, optional GST/HST number; admin approves each seller |
| Listings | Auction (1 to 10 days, optional Buy It Now and reserve) or fixed price with quantity; up to 8 photos; best offers; edit, end, relist |
| Bidding | Proxy bidding with eBay-style increments, outbid notices, automatic close |
| Search | Keyword, category, format, price, seller province, ships-to, sorting, pages |
| Checkout | Worldwide addresses, Canada Post service choice, Canadian sales tax by province, zero tax on exports |
| Shipping | Canada Post only: live rates through the Canada Post API, or built-in estimates until keys are added; flat-rate and free-shipping options; tracking numbers |
| Money | Buyer pays Canado; 3% fee; funds held, released and paid out on a daily, weekly, biweekly or monthly schedule |
| After the sale | Order pages, messages, feedback, buyer cases that freeze funds, full refunds, clawback from the next payout if the seller was already paid |
| Switch from eBay | CSV import that turns an eBay listing export into Canado listings |
| Admin | Seller approval, listing removal, orders, cases, payouts, sales tax owed, password reset links |

## The money rules

All set in `.env` (see `.env.example`) and implemented in `src/lib/market.js`.

- **Fee:** `FEE_BPS=300` is 3% of the item price plus shipping, never on tax. Set `FEE_ON_SHIPPING=false` to charge it on the item price only.
- **Hold:** established sellers (5+ completed sales) have funds released 2 days after payment. New sellers have funds released when the buyer confirms delivery, or 7 days after tracking is added.
- **Payout schedule:** each seller picks daily, weekly (Tuesdays), every two weeks, or monthly (the 1st). A job runs each morning (Toronto time). Admin can also run payouts by hand.
- **Cases:** a buyer case freezes that order's funds until the seller refunds or admin decides.
- **Sales tax:** Canadian destinations are charged GST/HST/PST/QST by province on item plus shipping. If the seller is GST/HST registered the tax is paid out to the seller to remit; otherwise Canado keeps it to remit (shown on the admin overview). Rates live in `src/lib/geo.js`.

## Going live: what you must add

The code is complete, but these need accounts only you can open.

1. **Stripe** (`STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`). Without it the site is in test mode: payments are simulated. With it, buyers pay by card through Stripe Checkout and sellers connect a Canadian bank account through Stripe Connect (Express, country fixed to Canada) for automatic payouts. Point a Stripe webhook at `/webhooks/stripe` for `checkout.session.completed`. This code path is written but has not been run against a live Stripe account, so test it in Stripe test mode first.
2. **Canada Post developer account** (`CANADAPOST_API_USER`, `CANADAPOST_API_PASSWORD`, `CANADAPOST_CUSTOMER_NUMBER`). Without it, shipping prices are estimates from a table in `src/lib/shipping.js`, not Canada Post's real rates. The live rate call has not been run against Canada Post's servers yet.
3. **Hosting** with a persistent disk for the `data/` folder (SQLite database and photo uploads), HTTPS, `NODE_ENV=production`, a long random `SESSION_SECRET`, and `BASE_URL` set to your domain.
4. **Legal and tax review.** Holding buyers' money and paying it out is regulated in Canada. Have a lawyer confirm what registration applies to you, replace the draft user agreement at `/terms`, and have an accountant confirm the tax table and the rule for who remits tax.
